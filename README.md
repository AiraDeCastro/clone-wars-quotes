# Cold Open — Clone Wars Quote Widget

A home-screen widget that surfaces randomized quotes from *Star Wars: The Clone Wars* pre-credits cold opens, with one-tap sharing to social media.

See [docs/PRD.md](docs/PRD.md) for the full product requirements, or the [designed PRD artifact](https://claude.ai/code/artifact/a9dc14cf-86c8-47a1-a63b-cb4e1f451a62).
